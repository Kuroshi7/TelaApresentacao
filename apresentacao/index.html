Bateria WEB

Descrição:

--FINALIZADO--

A Bateria WEB é um projeto de uma bateria virtual desenvolvida com HTML, CSS e JavaScript. A página simula uma bateria real, onde cada tecla do teclado ou clique na tela reproduz um som de bateria correspondente. É uma aplicação interativa para explorar sons de bateria de forma virtual.

Aplicativo bancario em Java

Descrição:

--FINALIZADO--

O "ConnectBank" é um sistema bancário online desenvolvido em Spring Boot e Base de Data em FireBase, que permite aos usuários realizar operações bancárias básicas, como depósitos, saques e transferências. O sistema é projetado para oferecer uma experiência simples e segura aos clientes, permitindo que eles acessem suas contas e realizem transações e depósitos. (Por ser hospedagem gratuita pode levar algum tempo para o primeiro login ou criar uma conta)

Recursos:

  • Funcionalidades completas de um sistema bancário, incluindo depósitos, saques e transferências.

  • Implementação de segurança com tokens de sessão para proteger as transações.
